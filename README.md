## Descripción del Proyecto

El objetivo de esta práctica es implementar la lectura, procesamiento y exportación de datos utilizando ficheros planos y hojas de cálculo:

1. **Lectura y Procesamiento:** Carga de datos de origen y validación de estructuras.
2. **Generación de Ficheros de Texto (`.txt`):** Generación de informes planos formateados a partir del procesamiento de datos.
3. **Generación de Hojas de Cálculo (`.xlsx`):** Creación y exportación de libros Excel con resultados organizados y estructurados.
4. **Pruebas Automatizadas:** Verificación del correcto funcionamiento de la lógica de procesamiento y validación de salidas mediante tests.
